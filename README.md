# UI-тесты для  учебного сервиса Яндекс Самокат
link:    https://qa-scooter.praktikum-services.ru/

## Описание проекта
Автоматизированные UI-тесты для проверки функциональности сайта Яндекс Самокаты (Scooter).   
Тесты написаны на Java(11) с использованием Maven(3.9.0), JUnit(4.0.0) и Selenium WebDriver(4.25.0).

## Поддерживаемые браузеры
- Google Chrome (Version 140.0.7339.208, 64-bit)
- Mozilla Firefox (Version 143.0.1, 64-bit)

## Запуск тестов
Для запуска тестов в Google Chrome, вызови в терминале —
```
mvn clean test
```

Для запуска тестов в Firefox, вызови в терминале —
```
mvn clean test -Dbrowser=firefox
```


## Тестовые сценарии
1. Выпадающий список в разделе "Вопросы о важном"
   Проверка, что при нажатии на стрелочку раскрывается соответствующий текст.

2. Оформление заказа самоката
   Проверка всего позитивного флоу с двумя наборами данных.
   Точки входа в сценарий: кнопка «Заказать» в верхней и нижней части страницы.

- Позитивный сценарий включает:
*Нажать кнопку «Заказать».
*Заполнить форму заказа.
*Проверить, что появилось всплывающее окно с сообщением об успешном создании заказа.

Для тестирования сценариев использовалась параметризация (запуск с разными наборами данных).
